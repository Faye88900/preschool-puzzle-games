# 第三关一键闪避

## 玩法约定

玩家看懂预警后按一次闪避，再用风力魔杖反击。目标是通过简单的观察和操作获得无伤胜利；站着不动仍会受伤。失败沿用现有受伤保护和检查点，不增加体力、装备、连招或新敌人。

循环：盾兵停步蓄力、显示路线与按钮提示 → 玩家按闪避 → 盾兵向锁定方向冲刺 → 无论是否命中都放盾喘气 → 提示吹风 → 命中一次，重复后击败盾兵 → 引导去凉亭找风帆晶石。

第一只骑士维持一击教程及开门流程。第二只教会闪避反击；Boss 保留原攻击规则，玩家也能使用新闪避能力。

## 操作与参数

| 项目 | 当前值 |
| --- | --- |
| 输入 | PC 用左右 Shift；触控设备显示独立“闪避”按钮 |
| 有方向输入 | 沿摇杆或键盘方向闪避 |
| 无方向输入 | 优先选择正在出招的可见敌人，沿其攻击方向的侧面闪避；一侧受阻时换另一侧 |
| 无附近敌人 | 沿角色朝向移动 |
| 闪避 | 0.4 秒，70 毫秒加速、130 毫秒减速，峰值速度 10.4；停止输入时收住，持方向时接回走动 |
| 保护 | 0.48 秒，独立于原受伤无敌；地面青色圆环表示保护 |
| 冷却 | 1.6 秒；按钮填充和数字显示恢复进度 |
| 第二只盾兵 | 4 单位内开始预警，首次 2 秒、后续 1.4 秒 |
| 方向锁定 | 预警开始即锁定；玩家远离不取消攻击 |
| 冲刺与喘气 | 冲刺 0.65 秒；之后放盾 3 秒 |

保留 Rapier、1/120 固定步长、现有胶囊体和 CCD。闪避使用物理速度，另检查地图边界和关闭的叶纹门，避免跨过未开放区域。坠落恢复不受闪避保护阻止。

暂停冻结闪避、保护和冷却；对话和乘船期间不能开始闪避。重置及检查点恢复会清除闪避状态。减少动态效果模式去除身体侧倾，保留移动、保护和静态提示。

## 实现范围

- `src/maze.ts`：输入、自动选侧、物理移动、保护与生命周期、盾兵状态、攻击路线、按阶段显示的提示。
- `src/maze.css`：两列按钮布局和冷却/重点状态，仅作用于第三关。
- `src/maze-text.ts`：中、英、马来文按钮、预警和反击提示。
- `src/ui.ts`：开放现有按钮绑定方法供第三关复用，绑定逻辑不变。
- `tests/maze-dodge.mjs`：新能力和无伤战斗的聚焦检查。

## 流畅度修正

旧版把横向速度直接切到 12，再在动作结束时清零，同时直接写入侧倾角。现在从按下时的实际速度平滑进入闪避，末段平滑接到当前方向输入；侧倾随动作渐进变化。静止起步的实测距离约 3.12，保持原先约 3.2 的避让范围。没有增加新的动画库、模型或物理引擎。

参考官方资料中的设计方向，参数由本项目自行调校：

- [Hades 官方更新记录](https://www.supergiantgames.com/blog/hades-updates/)：冲刺攻击恢复和输入衔接作为单独调校项。
- [任天堂卡比操作说明](https://www.nintendo.com/en-ca/whatsnew/new-kirby-goodies-2-controller-tips-for-the-latest-game-and-the-second-read-along-book/)：方向闪避、避伤及闪避后反击。
- [Insomniac 动画制作说明](https://blog.playstation.com/?p=352844)：角色状态需要通过清楚的动作表达。

本轮重跑 TypeScript、Vite 构建和 `tests/maze-dodge.mjs`：输入 50 毫秒内已有位移；逐个物理步的最大速度变化约 1.84，侧倾最大变化约 0.029 弧度；无输入时收住，有输入时连续接回走动。无伤战斗、双指触控、暂停/重置、碰撞和减少动态效果仍通过。完整流程与骑士/渡船回归沿用下方此前记录，本轮未重复运行。
