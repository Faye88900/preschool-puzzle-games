# 风语花园扩建与花坛位置调整

此页是扩建阶段记录。用户随后明确纠正“大 Boss 必须坐船前往”；原北侧陆路已移除，当前路线与验证以同目录 `ferry.md` 为准。

本轮按用户反馈扩大游戏地图，并把花坛移到图 2 玩家站立的拱门前左侧，正面按用户最新要求朝画面右侧，纵向排列。

## 空间与路线

- 实际网格由 21×23 扩为 31×23，世界宽度 105 → 155。保留原来的坐标原点，花匠区、第一只骑士、桥、最终守卫和原出口不平移。
- 原庭院保留，右侧增加长弯路，凉亭移至世界 `(85,-5)`，码头移至 `(100,-10)`；上方长回廊接回原 checkpoint 和守卫区。移除原来庭院直达北侧 checkpoint 的短接线。
- 使用同一套行走网格计算最短距离：第一只骑士至最终守卫 95 → 225；盾兵至宝箱 15 → 90；宝箱至最终守卫 55 → 100。单位为世界单位，实际走位距离会略长。
- 花坛中心为世界 `(21.5,14.5)`，朝向 `+X`；相对前一版前移约 5 单位并向右移 1 单位。它在拱门前左侧，沿道路纵向排列，不占中央通道。

## 实现范围

- `src/maze-map.ts`：扩宽网格、更新道路和凉亭/码头/NPC/宝箱位置，提供由现有坐标函数算出的 `MAP_CENTER`。
- `src/maze-ground.ts`、`src/maze-island.ts`、`src/maze.ts`：同步移动新增宽度对应的草地边界、浮岛岩壳、基础碰撞与远景；原桥洞位置保持对齐。
- `src/wind-garden.ts`：花坛以局部坐标构建后整体旋转、碰撞尺寸同步旋转；凉亭、池塘、码头和船使用分组平移，物体本身尺寸不变；延长路面石块引导并增加沿路树木。
- 修正了实走发现的凉亭侧柱挡直线问题：路面引导从正面进入凉亭。

## 验证

- TypeScript 与 Vite 构建通过，保留项目原有大包提示。
- 扩建地图测试 `tests/wind-garden-map.mjs` 覆盖地图宽度、最短路增长、花坛位置与方向、桥/钥匙进度锁、19 段连续物理行走、花坛与骑士碰撞、码头行走/跳跃护栏、盾兵挡风与受击、宝箱、暂停和重置。详细结果见 `test-results/wind-garden-expanded/report.json`。
- 钥匙拾取、返程捷径解除、原出口开门和终点通关触发均通过；最后状态为 `key=true / exitOpen=true / state=qualified`。
- `tests/maze-ground.mjs` 通过：地面世界 UV 连续、草边朝上、原桥洞不偏移、浮岛几何有效、桌面/竖屏/横屏、无浏览器或资源请求错误。
- 新地面边界为 X `[-52.5,102.5]`，Z `[-52.5,62.5]`；花坛正面方向向量为 `[1,0,0]`。重置前后物理资源数量一致（184 bodies / 253 colliders）。
- 场景静态合批为 46 meshes / 87,566 triangles；庭院桌面视角为 191 calls / 179,326 triangles。未进行真实手机帧率测量。

本轮没有新增花儿合唱、问答、乘船或音频，没有打包或部署。验证含状态加速与实际运动输入状态驱动，不等同于真人从头游玩；本轮未重新执行完整花匠任务链。继续沿用前轮记录的技能参考与视觉检查清单。
