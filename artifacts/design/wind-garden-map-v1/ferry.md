# 坐船前往 Boss 岛 · 设计纠正与实现

之前将帆船当作景物并保留陆路 Boss 区，是对用户设计的误解。本轮以用户明确说明的“必须坐船去打大 Boss”为准，修改地图连接和实际往返流程。

## 当前路线

花园入口 → 盾兵庭院 → 长花园路 → 凉亭左侧花坛 → 凉亭宝箱取得风帆晶石 → 码头乘船 → 独立 Boss 岛 → 战斗取得钥匙 → 乘船返回花园 → 新开的捷径 → 古树出口。

- 主花园保持 155 单位宽，保留约 160 单位的第一只骑士至码头的步行路程。按最新截图，花坛移至凉亭左侧玩家位置 `(75,-4.4)`，正面仍朝右；南侧通道继续连通宝箱和码头。
- 删除北侧回廊与原陆地 Boss 区；Boss 移到世界 `(145,-30)`，独立岛左侧码头为 `(130,-15)`。
- 两岛间有真实无地面碰撞的水面间隔。无论是否持有钥匙，从主花园都不能步行到 Boss 岛。
- 船程约六秒，包含登船、渡水和靠岸。使用既有 E / 触控互动按钮。途中暂停会冻结整段船程，移动和跳跃输入不会让角色掉下船。
- 风帆晶石是船的前置条件；开启凉亭宝箱后，HUD 显示晶石，船上晶石亮起。原有 `treasure` 状态复用为晶石拥有状态。
- 到岛时更新安全检查点。战斗失败在岛上码头恢复，船仍可使用；未胜利也能提前返回。
- 减少动态效果模式直接完成渡船并更新镜头。重置会恢复船的位置、角色物理、登船护栏和进度。
- 三语目标提示、宝箱奖励、登船/返回按钮均已更新。

## 文件与实现边界

- `src/maze-map.ts`：移除陆路连接，Boss 和岛上码头位置，以及岛上可行走区域。
- `src/boss-island.ts`：独立岛地面、岩壳、护栏、木码头、Boss 场地与水面。
- `src/wind-garden.ts`：船改为可移动局部模型，登船端栏独立；晶石为独立可见部件。
- `src/maze.ts`：船程状态、暂停、镜头跟随、检查点、失败恢复和重置；船程中暂停角色的动态物理，靠岸时恢复。
- `src/maze-text.ts`：中文、英文、马来文的晶石与渡船目标。
- 调整原地图、广场和完整流程测试中“陆路可达 Boss”的旧断言。

Boss 沿用原来的最终守卫模型、盾牌规则、三次有效命中和钥匙逻辑。本轮不新增敌人或驾驶系统，不新增依赖及音频资产。花儿唤醒合唱和凉亭问答尚未实现；宝箱目前沿用原有打开动作来取得晶石。
