# 芽芽 · 风之花园向导 — 人设提案 v1

状态：用户已确认按此方向建模。当前 Three.js 实现与正侧背视图见 `artifacts/models/garden-scout-v2/`；这是概念阶段保存的原图。

主文件：`scout-character-sheet-v1.png`，包含正面、侧面、背面，以及叶帽、风车手杖和地图包的细节。侧视绘画带有少量透视，属于视觉设计参考；正式建模时仍需统一各视图的包带、饰扣及叶片结构。

生成方式：内置 `image_gen`；完整提示词见 `prompt-v1.txt`。参考输入为本项目已存在的 `artifacts/models/garden-scout/front.png`（仅用于角色种族比例）与 `artifacts/models/garden-scout/production/garden.png`（仅用于世界观和配色）。新图是设计参考，不是已实现的网格、拓扑、材质或动画效果。
