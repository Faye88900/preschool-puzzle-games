# 风帆渡口：小船、栏杆与池塘移除提案

范围纠正：整体世界仍是空岛，迷宫外围保留原有云海与悬浮小岛。“海”仅指码头到守卫岛这段局部海湾，不能扩成整个世界的背景。按用户进一步要求，局部海湾从50×44加宽为90×70，守卫岛向外移35，航线约58、航行9秒。整岛与云海实景见 `artifacts/models/ferry-coast-scope/`。本稿海边细节仅用于局部码头，不取代空岛世界观。

状态：小船、两端木桩绳栏/栈桥、海面、沙滩礁石岸线、系船绳/绳圈、叶形灯和方向牌均已接入第三关，池塘已移除。按用户最新要求，登船口正前方不再围绳，系船绳位于侧边。设计图使用内置 `image_gen`；实际几何、材质与布局是按游戏尺度制作的本地 Three.js 实现，证据见 `artifacts/models/ferry-coast/`、`artifacts/models/wind-sail-boat/` 和 `artifacts/models/rope-dock/`。

用户明确的优先项：重做船、重做栏杆、删掉截图中的椭圆池塘。用户进一步明确这里是海，不是云海。当前方向为海边花园的风帆渡口，船浮在真正的海面上，栈桥木桩入水，草地与礁石岸线连接海面，远处海岛从海中升起。旧云海解释已被用户纠正，不应继续用于制作。原来的凉亭问答宝箱到码头的必经路线保留。

小船：曲面木板船壳、真实船舷、座椅、脚下空间、小舵与桨、鼓起的奶油色船帆和叶形风元素、保留风帆晶石安装点。比例按少量玩家乘坐的小船设计。概念图的细小构件与不同视图需在正式建模时统一，不能逐像素照搬所有生成细节。

栏杆：圆木桩、麻绳包扎、自然下垂的绳栏，降低整段围栏的视觉高度；登船侧保留明确入口。支撑木桩及斜撑让栈桥与岛缘有真实连接。物件留在边角，中央通道与停船点保持清楚。

池塘：移除现有局部池塘的水面、椭圆边框、荷叶、圈状水纹及相关水生装饰；此位置恢复连续草地/沙地。码头外侧改为开放海面，补齐浅海到深海的色差、木桩水线、船体吃水、水面细波与岸边少量浪花。

参考研究（借鉴空间组织与功能识别，所有本项目造型为新设计）：
