# Boss 庭院摆放与配色优化

日期：2026-10-30。范围：已有正式模型的摆放、材质颜色及地面层次。

## 其他游戏参考

- [《对马岛之魂》环境美术负责人 Joanna Wang 的官方说明](https://blog.playstation.com/2020/07/09/crafting-the-world-of-tsushima/)：限制局部植物种类、强化颜色，使不同地点拥有明确的主题；自然与人工秩序共同组织环境。用于本项目的提炼是收敛主色、强化遗迹与植物的冷暖关系，外围动态继续衬托中央静态战斗场。
- [《对马岛之魂》首席概念设计师 Ian Jun Wei Chiew 的官方说明](https://blog.playstation.com/2020/10/26/from-brush-to-blade-the-concept-art-process-behind-ghost-of-tsushima/)：场景从叙事主题、参考和布局迭代开始，主题与颜色需要明确表达。用于本项目的是“守卫遗迹庭院”主题，保留一座巨剑作为主要地标。
- [《柯娜：精神之桥》首席环境美术 Julian Vermeulen 的场景作品](https://kingjulianv.artstation.com/projects/zDQYBw)、[开发商介绍](https://emberlab.com/kena/)及[发行商店公开场景图](https://store.epicgames.com/en-US/p/kena-bridge-of-spirits--deluxe-edition)：参考其被自然重新覆盖的遗迹题材，以及物件组合、植被与路径的关系。本文中的配色和具体摆法均为本项目自行设计，不是原游戏的技术参数，也没有导入对方素材。

## 已实施

| 层次 | 调整 | 用途 |
| --- | --- | --- |
| 外圈 | 青灰色错缝石板，细缝及逐块轻微色差 | 衬托浅色圆台，补足原来平整灰米色地面的尺度 |
| 中央 | 保留原叶纹纹理和半径 15 的圆台；叶纹偏青玉，金色纹路适度增强 | 保持战斗区域、Boss 和攻击预警清晰 |
| 主要地标 | 树根从浅米色改为深木色；剑身偏深青，金属和风印保留亮点 | 巨剑、树根和天空能够分层 |
| 围墙及道具 | 暖砂岩墙体和金色压顶；玉色雕像、石碑和浅青水槽 | 统一材质角色，同时拉开冷暖 |
| 后左侧 | 风铃世界位置 (169.5,-39.5)，营火 (171.5,-41)，武器架 (173.5,-43) | 组成由低到高的营地小组，收紧原来分散的道具 |
| 植被 | 调整 7 处种植点及其附属花、蕨位置，靠拢前左园艺角和后侧树根 | 打破均匀沿墙排列，保留行走围边 |

颜色只应用在 Boss 岛上的独立材质克隆；工厂模板、其他岛、原始地坪贴图及远景岩石的位置保持原状。没有新增模型、灯光、渲染通道或依赖。外圈砖缝和圆台颜料在现有材质中完成。

## 检查与证据

- `npm run build` 通过；既有大 bundle 提示仍存在。
- `tests/courtyard-art-pass.mjs --baseline` 和最终检查保存相同镜头的前后画面，含入口、总览、后场、水景和桌面/手机战斗。
- 材质隔离断言通过：岛内树根为新木色，工厂树根仍为 `#e6d2ae`，几何共享，圆台继续使用同一张已加载纹理。
- 同一减少动态战斗镜头，前后均为 252 calls / 382,099 triangles / 78 points；生产普通镜头为 255 calls / 382,459 triangles / 106 points，784 geometries / 35 已上传纹理。后者与前者使用的动态及可见性状态不同，不直接互减。
- 生产主回归通过：中央清场、道具底座碰撞、码头往返、八方向闪避、攻击预警、前景淡出、手机横竖屏。预警改为更浓的橙色填充和深橙边线，移除色调映射带来的褪色；攻击时序与范围不变。最终地面预警画面与隐藏预警对比，有 5,917 个像素至少一个通道差值超过 40/255，无 shader / console / HTTP 错误。
- 植被检查通过：117 处布置，16 meshes / 94,426 triangles；最近顶点平面半径约 17.376，仍在半径 15 圆台之外；码头侵入和流水相交均为 0，6 条路线及重置正常。
- 风铃、武器架、营火移动后的专用检查通过：底座阻挡、选择性淡出、低矮营火可走过、重置及手机截图正常；物理数量维持 192 bodies / 265 colliders。对应三份旧场景坐标测试同步更新。
- 最终画面：[总览](../../models/courtyard-art-pass/after/overview.png)、[战斗](../../models/courtyard-art-pass/after/combat.png)、[之前总览](../../models/courtyard-art-pass/before/overview.png)。详细 JSON 与截图存于 `artifacts/models/courtyard-art-pass/`，生产预警等存于 `artifacts/models/boss-courtyard-blockout/`。

本次不宣称整款游戏已达到 AAA 或手机性能目标。尚未做完整 Boss/渡船通关、手机真机帧率测试或部署；既有全场景的绘制和几何资源数仍高于通用手机起始预算。
