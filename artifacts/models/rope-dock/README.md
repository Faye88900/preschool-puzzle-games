# 木桩绳栏与栈桥

最新状态：用户要求登船处敞开后，入口围绳、内侧木桩/挂钩及端部碰撞已删除，原绳索组改为侧边系船绳；另有桥角绳圈和系船桩。当前模型仍为15个网格，三角面减至29,124，每端为板面/两侧共3块碰撞区域。海面与岸线已完成，桥下支撑已露出，完整状态见 `../ferry-coast/README.md`。以下保留最初木桩绳栏版本的制作记录；其中入口门绳、旧全局碰撞数量和待做海岸的说明已经被本段及海岸记录取代。

按海边码头稿 `artifacts/concepts/wind-sail-dock-2026-10-27/dock-design-v2-sea.png` 制作。源文件 `src/rope-dock.ts`，接入花园和守卫岛两端码头。原先偏高的双横杆改为圆木桩、浅色木桩端面与年轮、螺旋绑绳、编织下垂麻绳、叶形小挂饰；桥面补木板拼缝、固定钉、边梁、横梁、下方木桩与交叉斜撑。入口中间留出约1.5米的柱间净空，用独立低绳及挂钩标出登船口，航行时随原有 gate 状态隐藏。

木纹由本地 Canvas 绘制，所有绳索、木桩、支撑均为真实几何体，不含新依赖或外部资产。花园栈桥长4.4、宽3.3，守卫岛栈桥长4.4、宽4.6；沿用既有位置、登船方向和往返流程。花园版本15个网格、34,152个三角面；木桩最高Y=1.356、桩底Y=-1.520、板面Y=.095。两端各有一块与桥面齐平的地板碰撞体及三条边界碰撞体，场景179个刚体/248个碰撞体。
