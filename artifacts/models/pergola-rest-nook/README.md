# 藤架休息角 Three.js 模型

- 源码：`src/pergola-rest-nook.ts`，入口 `createPergolaRestNook()`。
- 原创概念参考：`output/art-direction/level3-old-oak-plaza/pergola-rest-nook-design-v1.png`。
- 枢轴：地面中心；Y 向上，+Z 为正面；约宽 5.451 × 高 3.695 × 深 3.407 场景单位。
- 9 个合并材质网格，39,156 三角形；GLB 1,163,484 字节，已导出回读验证。源代码缓存克隆共享几何和材质。
- 木、石、铜和青绿叶饰材质复用环树座椅，无新增纹理。无新依赖、外部模型或 3D 生成服务。
- `pergolaRestNookColliders` 提供九个局部盒碰撞；GLB 仅包含视觉模型，导入其他项目时需另接碰撞。
- 已接入第三关古树左侧，位置 (-17, 0, 35.4)，按用户截图移至出口左侧树篱前并清除占位石状绿植，正面朝 +Z；遮挡角色时淡化。
- `three-quarter.png`、`front.png`、`side.png`、`top.png` 为真实 Three.js 渲染；`metrics.json` 是检查记录。
- 验证：构建、独立模型、聚焦广场交互、构建预览桌面及手机视口；未重跑完整任务链，未验证实体手机性能，未部署，未更新 ZIP。

技术范围：静态原创道具；按材质合批，依赖现有关卡光照、阴影、DPR 和遮挡系统。不增加机关、坐下动作、灯光或后处理。单体预算不超过 10 网格 / 50,000 三角形 / 0 新纹理；实际 9 / 39,156 / 0。概念图中的细节简化为可维护的疏顶、格栅、藤叶和五朵白花；三视图冲突按统一三维结构解决。

同一广场概览实测从 973 次绘制 / 756,992 三角形变为 974 / 771,856；纹理仍为 26。该视图包含整个既有关卡，原有全场景开销偏高，不能据此推断手机帧率。
