# 花坛边框模块 Three.js 模型

源码：`src/flowerbed-edging.ts`；原创概念：`output/art-direction/level3-old-oak-plaza/flowerbed-edging-design-v1.png`。

## 文件与接口

- `createFlowerbedEdging('straight')`：三块直段，沿本地 +X 从 0 到 1.8，GLB `flowerbed-edging-straight.glb`，32,416 字节。
- `createFlowerbedEdging('curve')`：四块弧段，中心线半径 1.2、转角 90 度，从 (0,0) 向 +X 出发，在 XZ 平面转向 +Z，终点 (1.2,1.2)。GLB `flowerbed-edging-curve.glb`，66,868 字节。
- `createFlowerbedEdging('end')`：叶饰端头，沿本地 +X 从 0 到 0.6。GLB `flowerbed-edging-end.glb`，53,500 字节。
- `createFlowerbedBorder()`：两件直段、四件弧段拼成的完整闭合椭圆边框，前方保留独立叶饰。GLB `garden-flowerbed-border.glb`，336,728 字节。

模块以地面为 Y=0，Y 向上，统一高 0.48、石框厚 0.36；石缝与圆角使实际包围盒略有差异。组合包围盒约宽 4.562 × 高 0.480 × 深 2.786。边框只有 2 个合并材质网格、5,744 三角形，复用环树座椅奶油石和青绿材质，无新增纹理。

三个独立模块和组合模型均已导出后回读，尺寸/面数保持一致。GLB 仅有石框与叶饰，不包含花草、土壤或物理碰撞。`flowerbedBorderColliders` 提供 18 个沿直段与弧段分布的盒碰撞；实际集成需单独创建刚体。

## 场景接入

古树广场外围两处现有花坛改用新边框，位置为 (-17.2,0,49.2)、(9.2,0,49.2)。花草独立保留，十朵花的位置略收拢以避免穿石，土壤根据弧线重画。其余园丁花坛继续用原工厂，环树座椅缺口、藤架和风叶路标不改动。

遵循项目既有缓存克隆与按材质合批模式。单体/组合目标为最多 2 材质、0 新纹理、组合少于 20,000 三角形；实际组合 2 网格、5,744 三角形。植物和土壤加入既有低层植物批次。沿用关卡光照、阴影和 DPR，不新增灯光、后处理、动画或任务。

## 用户修订：完整围合与删除草丛

按截图反馈，两处花坛都由开放边框改为完整闭合椭圆；土壤同步闭合，花朵与路灯保留。删除花坛周围四簇大灌木、六簇小灌木、六簇草叶以及通用场景中邻近的两簇灌木，避免遮住石边。六朵原本散在石框外的白花移入框内，每处为原有十朵花加三朵白花。其他位置的绿植保持原样。

组合 GLB 已重新导出回读，当前 336,728 字节，5,744 三角形，2 个合并网格；三个独立模块不变。构建与聚焦广场检查通过；实体手机和完整任务链未重跑，ZIP 未更新。前文最初开放版本的视口预览记录为历史验证，不代表本次再次验证所有生产流程。
