# 空岛世界与局部码头海湾

用户纠正了范围：整体是空岛，只有码头这一段是海。上一轮错误地添加了650×650海面，并把低云与远岛移成了全球海景；本轮已恢复。

- 海面最初收回50×44，随后按用户“大一点、不要像短短过河”的要求加宽为90×70，中心(135,-.65,-12)，边界X=90…180、Z=-47…23，仅覆盖该码头分区。
- 守卫岛向外移35，实际航线约57.8，为原来的约2.5倍；往返各9秒，保留原来的上下船过渡。地形、实体碰撞、可行走区域、守卫/钥匙、停靠点与恢复检查点同步移动。
- 沙岸与礁石同步收回码头范围，保留局部的岸线裁切、木桩/斜撑、系船绳与绳圈、叶形灯、方向路牌及敞开登船口。
- 迷宫外围恢复原有120朵低云和远处6座悬浮小岛的高度，不再铺全球海面。
- 海岸环境现在为9个网格、16,760个三角面；未新增依赖、外部资产或场景灯。

`island-overview.png` 是实际场景的整岛检查图，使用临时正交镜头并关闭雾，以看清范围；`clouds-west.png` 是西侧云海检查图。源文件修改前备份在 `before/`。码头近景、手机图与测试结果仍保存在 `../ferry-coast/` 和 `../rope-dock/production/`。

`tests/ferry-coast.mjs` 验证水面精确边界、四处范围外点没有水面、低云高度[-7,-2,3,8]及远岛高度[8,-3,10,2,5,-6]恢复原值，并保留海面像素/暂停/减少动态、岸线碰撞、开放入口、系船状态和手机返程检查。`tests/rope-dock-scene.mjs` 验证构建后同样的局部水面及云高，同时检查实际走过风车桥和往返乘船。

另验证了旧岛位置没有残留隐形地板、新岛登船地板Y=.095和岛内地面Y=0。`before-expansion/` 保存加宽前的相关源文件。用户要求之外的主岛路线、问答和奖励保留。未测实体手机性能，未部署或打包ZIP。旧全球海景及50×44小海湾的说明与截图不代表当前设计。
