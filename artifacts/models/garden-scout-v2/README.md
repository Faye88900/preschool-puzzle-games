# 芽芽：按人设图制作的 Three.js 模型

参考：`artifacts/concepts/garden-scout-2026-10-27/scout-character-sheet-v1.png`。本轮在原有圆润角色基础上重做服装和道具：五片弯曲叶帽、卷叶帽冠、风向徽章、带叶脉与缝线的披风、奶油色围巾、皮质地图包与宽挎带、空心地图卷轴、鞋底及三叶风车手杖。织物使用本地 128×128 CanvasTexture，其他材质用标准 Three.js 材质区分，没有增加灯光、依赖或碰撞体。

真实网格：37 个材质合批网格、34,068 三角面；静态包围盒约 1.774×1.821×1.290。游戏缩放 0.9，根节点 y=0.612，最低鞋底落在地面。运行时直接使用工厂，GLB 为可检查的静态导出；招手和风车动作由运行时函数驱动。

固定朝向通路（yaw=π−0.35），已移除根据玩家位置旋转的分支。玩家进入六单位范围时，空手抬起并摆动；走远后恢复休息姿势。持杖手不招手。暂停保持动作；减少动态效果时使用静态招呼姿势。普通镜头继续按原有规则跟随主角。

验证与证据：
- `tests/garden-scout-model.mjs`：几何有限值、服装结构、网格预算、GLB 导出重载、抬手和减少动态效果，以及实际模型的正、侧、背、四分之三视图与招呼姿势。头像从真实模型重新渲染。
- `tests/garden-scout.mjs`：玩家在 NPC 四个方向移动时，NPC yaw 恒定；相机相对玩家的普通偏移恒定；近处抬手摆动、远处休息；对话、旧园丁与主角头像分支、七种阶段提示、恢复生命而不赠送任务物品、暂停、重置；桌面、手机竖屏及短横屏。源码与生产预览分别输出 `scene/`、`production/` 证据。
- 宝箱问答、拾取动画有独立回归，结果沿用对应 artifacts 目录；构建保留原有大分块警告。

边界：小型浏览器模型保留了概念图的主要服装和道具，未逐像素复刻概念图的微观皮纹、织物起毛或写实布料模拟。未进行实体手机帧率测试、整关通关或线上部署。旧模型源文件及头像备份在 `before/`。
