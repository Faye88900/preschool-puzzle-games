# 风帆小船重做

依据 `artifacts/concepts/wind-sail-dock-2026-10-27/dock-design-v2-sea.png` 右上角的小船制作，运行时源文件为 `src/wind-sail-boat.ts`，由 `src/wind-garden.ts` 接入第三关。这轮只重做小船。

曲面木板外壳与内壁、奶油色船舷、封闭船尾、船底与两张座椅、船舵和舵柄、侧挂桨、绳结与铜环、绿色小旗、鼓起的叶纹帆、原有风帆晶石安装点均为实际 Three.js 几何体。木纹和帆布纹理由本地 Canvas 绘制，无外部模型、纹理或新依赖。晶石仍需先从问答宝箱拾取，船上副本才显示。

- `three-quarter.png`、`front.png`、`side.png`、`back.png`、`top.png`：模型原生渲染。
- `passenger-outbound.png`、`passenger-return.png`：按实际运行时两个载人位置渲染。
- `boat-hull.png`、`boat-deck.png`：分部检查图。
- `wind-sail-boat.glb`：包含晶石的静态独立模型，已导出并重新加载验证。运行时使用源工厂，航行逻辑不在此 GLB 内。
- `model-metrics.json`：21 个网格、25,136 个三角面；尺寸约 2.153 × 4.520 × 4.434；船壳采样厚度 .060；帆面鼓起 .420；四个脚下采样均为局部 Y=.62；56 个外部采样验证船底/座椅未穿出船壳。
- `production/`：构建后的本地游戏截图与结果。详情截图暂停航行、临时隐藏暂停菜单并调整检查镜头；手机截图隐藏菜单以查看船，均不改变运行时产品行为。
- `before/`：本轮之前的相关源文件备份。

验证：`npm run build`、`tests/wind-sail-boat-model.mjs`、`tests/boat-crossing.mjs`、`tests/wind-sail-boat-production.mjs`。既有乘船回归涵盖问答拾取/解锁、登船、去返程、暂停、死亡恢复、守关者与钥匙、原出口、重置与减少动态模式；构建后检查保留真实 tick，覆盖键盘去程、触屏按钮返程、脚下偏移、晶石状态、暂停和重置。脚本使用状态准备和近点定位，不构成人工从头完整通关。

海面、岸线、栏杆和池塘移除仍待后续实施；未验证实体手机性能或线上部署，未更新 ZIP。构建保留项目已有的大块体积提示。

实景检查同时修正了返程角色消失：上岸后的无敌闪烁在航行期间不再隐藏乘客，避免游戏时钟暂停推进时把角色冻结在隐藏帧。构建后测试会在返程航行时强制进入该闪烁阶段并验证角色可见。
