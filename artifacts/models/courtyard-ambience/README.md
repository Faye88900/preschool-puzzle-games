# 庭院环境动画与光效

2026-10-30，按已确认环境动效设计板接入第三关 Boss 岛庭院。此前查阅的游戏参考与原设计取舍见 `artifacts/concepts/boss-courtyard/ambient-motion-light-reference-notes-v1.md`。

## 实现

`src/courtyard-ambience.ts` 创建静态资源和更新控制器，`src/maze.ts` 在建筑遮挡材质隔离后接入，沿用既有海湾／水流环境时钟。没有额外计时器、动画循环、灯光、依赖、贴图或后期通道。

| 系统 | 当前行为 |
|---|---|
| 风与落叶 | 12 片实例叶子沿 z=±22.5 的外侧通道漂移，循环两端逐渐缩小；两条很淡的风丝随阵风显隐 |
| 风铃与布条 | 两处风铃的六片铃叶独立错相摆动；自由布尾做小幅弯曲，固定石台、铜架和结环 |
| 植物 | 四区合批网格用 GPU 按根部权重弯曲，草尖／花更明显，绿丛和藤较轻，苔藓固定 |
| 悬浮碎岩 | 三块独立挂点缓慢上下浮动并略微倾斜，不公转、不改变碰撞 |
| 巨剑 | 既有青绿风印／通道约 6 秒平滑呼吸，原始强度的 0.72–1 倍；橙裂光仅有更弱变化 |
| 阳光与光尘 | 两条很淡的稳定日光薄片、后侧 28 个低透明度光尘点；原流水继续使用已有实现 |

`src/courtyard-vegetation.ts` 在合批时生成 `aAmbientWind` 顶点属性，记录位移权重和相位。运行时不拆批、不修改原始顶点数组。零权重顶点 29,070 个，最大权重约 0.10925，所有苔藓权重为 0。运行材质私有克隆保留原模块材质，避免影响近景碎岩上的静态小植物；布条在已经隔离的建筑材质上安装 shader，保留原遮挡淡出关系。

所有动画基于绝对环境时间计算，同一时间可重复。暂停／对话沿用现有环境时钟停止规则。减少动态模式使用中性静止姿态、稳定原始风印亮度，并隐藏落叶、光尘和风丝；稳定日光薄片保留。重置时环境时钟归零，模型、材质和物理代理复用。没有新增镜头抖动、闪屏、地面光纹或环境音效。

## 检查

`npm run build`、`tests/courtyard-ambience.mjs`、生产 `tests/boss-courtyard-blockout.mjs` 通过。测试沿用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_BROWSERS_PATH` 和 `TEST_URL` 环境变量；专项测试使用开发服务，生产庭院回归使用预览服务。

- 时间推进时铃叶／岩体／光印及粒子改变；暂停后的全部环境状态一致，减少动态在不同时间输入下保持一致；重置回到原岩体位置，GPU 资源计数保持一致。
- 孤立 GPU 场景中，植物变化 43,718 像素，布尾变化 3,697 像素；同时间重画和减少动态的前后变化均为 0，无 shader 错误。
- 实际键盘 D 输入仍能移动玩家；阵风峰值时 Boss 扇形攻击预警可见。叶片／光尘的最近平面半径约 22.52／20.05，中央半径 15 圆盘不集中放置粒子。落叶在循环边界前后缩放约 0，避免跨场跳动。
- 生产回归覆盖 116 点中央地面、六段通行、八向闪避、道具碰撞、前景淡出、预警及桌面手机画面；物理数仍为 192 bodies／265 colliders，无 page／console／HTTP 错误。

新增效果 4 次绘制、364 三角形、28 个点；双面薄片使用 `forceSinglePass`。生产中央镜头 253 calls／381,790 triangles／106 points，原为 249／381,426／78；场景记录 784 geometries／35 已上传纹理。植被和布条 shader 不新增几何绘制。既有全场成本超通用手机起始预算，这些数值不是手机真机帧率。

## 画面与运动证据

`overview.png`、`chime-closeup.png`、`plants-closeup.png`、`sword-closeup.png`、`combat-warning.png`、手机横竖屏图和 `reduced-motion.png` 已人工查看。分时关键帧展示了铃叶／布尾、草叶、碎岩和光印变化，未见铜架移动、树根变形或中央新增遮挡。

`gameplay-motion.webm` 的环境时钟覆盖 0–10 秒；`chime-motion.webm` 和 `plants-motion.webm` 各覆盖 0–4 秒。`*-frame-*.jpg` 为过程关键帧，`metrics.json` 记录时钟终值、采样数、资源和状态。录制使用固定环境时钟采样，游戏逻辑仍按原固定步长推进；当前自动化采样较稀疏，视频仅验证姿态／循环，不代表实时流畅度，也不是完整战斗流程录像。需在正常浏览器和真机确认帧率。

沿用时间／状态断言、像素对照、关键帧、片段和固定截图，不建立严格像素基线。现有静态 GLB 仍是静态模型交付，运行时 shader／脚本动效在本项目中生效，没有导出新的动画 GLB。
