# 芽芽日常动作

在现有 Three.js 角色上增加一套 20 秒原地待机节奏：短暂停顿、抬起并观察风车手杖（约 2.5–6 秒）、休息、拿出地图展开查看（约 9–15 秒）、轻轻抬头思考、折回并收好地图、等待。伴随轻微呼吸、眨眼、披风与叶帽摆动。没有自动行走或根据玩家位置转身。

玩家进入六单位范围时，会中断日常动作，先收好地图，然后完成一组两次摆手的招呼（约 2.35 秒），再放下手等待交谈。持续站在附近不会循环招手；再次接近有八秒冷却。玩家可随时主动交谈，进入对话时立即收好地图并转为交谈姿势，不强制播放动画或弹出对话。

`src/garden-scout.ts` 使用现有游戏时钟更新演出状态，`src/maze.ts` 在暂停时不推进动画，重置时清理演出状态。减少动态效果时停用循环动作和风车转动。鞋子、鞋底、模型根节点的位置保持固定；身体/短靴的实心重叠仍保留。

道具和资源：独立的包内地图卷、可收展的曲面纸地图、连接手掌的袖子。地图图案为本地 Canvas 绘制的简洁路线示意（256×160），没有添加外部资产、依赖、声音、灯光或碰撞体。当前工厂含 41 个网格、32,868 三角面，比上一版增加 304 三角面和 3 个网格。隐藏的展开地图不会在普通等待姿势中绘制。

验证：
- `tests/garden-scout-model.mjs`：完整节奏、看图中途靠近先收图再招呼、持续靠近后等待、短暂离开不重复招呼、主动交谈中断、减少动态效果、重置；108 个身体/靴子连接样本、18 个鞋面/鞋底及地面接触样本；有限几何、预算、GLB 重载。`idle-checks.json`、`model-metrics.json` 保存结果。
- `tests/garden-scout.mjs`：实际生产预览中的检查风车、读图、抬头、靠近收图和招呼结束；角色朝向与普通玩家镜头、主动交谈、六种对话立绘、原有提示与奖励规则、暂停/重置、桌面与手机横竖屏布局。最新结果位于 `artifacts/models/garden-scout-v2/production/result.json`。
- `npm run build` 通过，保留已有大分块警告。

`idle-and-greeting.webm` 是实际模型的约 20 秒无声动作预览，包含一轮日常动作与看图中途靠近；`animation-timeline.json` 记录实际浏览器帧触发阶段。录制使用独立检查场景，`scene-reading-map.png` 则是生产预览中真实游戏场景的近景。GLB 为静态休息姿势检查导出，运行时动作由代码驱动，不是动画剪辑包。旧源文件在 `before/`。

未进行实体手机帧率、整关通关或线上部署验证。
