## 模型与运动

- 风车 `createGardenWindmill()`：奶油石分层塔身、暖木箍、青绿屋顶、铜轴与四片奶油色风帆。`rotor` 局部枢轴 (0,2.5,-0.86)，沿用原先绕 Z 旋转；模型正面朝 -Z，场景沿用 Y=PI 的朝向。
- 桥 `createGardenBridge()`：近岸原点为 X=0，远岸 X=5；活动 `bridge-deck` 局部 Y=.2，8 块木板、双层护栏、铜钉和铰链，绕 Z 抬起1.15弧度。`bridge-abutments` 固定在两岸，桥升起时不动。放平后板面高度和原桥相同。
- 双门 `createGardenGate('exit'|'shortcut')`：固定组 `gate-frame` 包含石柱和拱形木梁；活动组 `gate-grille` 包含竖栅与金色锁孔。门栅本地 Y=-4 时完全进入地面，门框保留，通道净空可通过角色。
- 2026-10-20 接入出口标识方案 A：`exit-nameplate` 固定在出口门楣上，铜边、深青绿底、奶油字和向前箭头，叶徽上移 .37 单位以留出间距；出口门整体高度变为 4.4828。原细杆出口牌删除。工厂第二参数为现有本地化出口文案，按文字缓存；默认导出的 GLB 为中文“出口”。捷径门不加铭牌。门栅下沉时铭牌位置不变。
- `src/maze-art.ts` 的旧 `windmill` 导出指向新工厂，现有调用无需改变；`src/maze.ts` 创建新桥和双门，原桥进度、关键任务和开门判断不变。
- GLB 保存默认关闭/放平状态，不含动画剪辑或 Rapier 刚体。Three.js 在游戏中驱动转子、桥面和门栅，导入其他项目时需单独实现这些控制和碰撞。

## 美术与资源

以已生成的美化设计图为造型依据，复用环树座椅的木、深木、奶油石、黄铜和青绿材质与纹理；增加无贴图的奶油帆布、暗色锁孔及深青绿铭牌材质。铭牌使用一张本地 CanvasTexture 渲染文字和箭头，替代原独立路牌纹理，不增加依赖或外部3D资产。静态和活动部分分别按材质合批，缓存克隆共享资源，保留局部运动枢轴。

单件预算：最多14网格、40,000三角形；四件实际均低于目标。沿用既有灯光、阴影、DPR，不增加后处理、光源、地面草丛或任务。桥墩与门柱按可见轮廓补静态碰撞；风车塔身有简单圆柱碰撞。原门阻挡体仍为5×4×1，原桥阻挡体仍为5×5×5。

概览从988次绘制/790,206三角形/25纹理变为946/834,782/25：合批减少42次绘制，曲面和细节增加44,576三角形。场景原有整体开销仍较高，未测实体手机帧率。
