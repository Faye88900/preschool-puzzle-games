# 芽芽脚部连接修正

问题：旧鞋面为扁球体，和身体的接触区域很小，独立空心鞋口环无法填充踝部。斜上方观察时，身体下方会露出间隙；薄椭球鞋底也缺少完整鞋底的外观。

修正仅涉及 `src/garden-scout.ts` 的靴子：
- 鞋面与鞋底分别使用封闭的旋转截面，保持圆润鞋头、棕色鞋底包边和相同的最低高度。
- 实心短靴筒贯穿鞋跟与身体下缘，顶部隐藏在身体内部，覆盖完整呼吸动画的起伏。
- 鞋底有宽的平底接触面，世界最低点仍为 y=0（根节点 y=.612、缩放 .9），角色位置和尺寸上限不变。
- 沿用现有颜色和材质；32,564 三角面、38 个合批网格，较修正前减少 1,504 三角面，增加一个网格。

`tests/garden-scout-model.mjs` 用实际网格射线检查 54 个身体/靴子连接样本（呼吸的三个时刻），最小重叠约 .1404；18 个鞋面/鞋底样本最小重叠 .0170，平底世界地面误差小于 1e-8。另有几何有限值、GLB 导出重载和招手/减少动态效果检查。这里保存导出的真实静态 GLB、正侧背视图、斜上方视图与脚部近景。修正前源文件及视图保存在 `before/`。

`tests/garden-scout.mjs` 在生产预览继续验证固定朝向、近处招手、普通玩家镜头、六种对话表情和手机横竖屏，全部通过。为检查外观，额外拍摄游戏内近景后立即恢复普通镜头；没有改动游戏镜头代码。本次实际场景截图与结果在 `artifacts/models/garden-scout-v2/production/` 的 `scout-feet-close.png` 和 `result.json`；近景也保存为本目录的 `scene-close.png`。

未改动对话立绘、任务规则或碰撞。未进行实体手机测试、整关通关或线上部署。
