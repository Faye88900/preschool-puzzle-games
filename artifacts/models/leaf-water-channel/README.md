## 模型与资源

`src/leaf-water-channel.ts` 依据项目生成的 `artifacts/concepts/boss-courtyard/three-tier-leaf-water-channel-design-sheet-v1.png` 制作可编辑 Three.js 模型。三片石叶具有封闭厚底、凹腔、逐段槽沿、低位叶尖溢水口和槽底叶脉；岩块和淡色树根承托，附少量苔藓垂叶。浅米石材、灰绿内壁、浅金叶脉和半透明青绿静态水面区分层次。

总计 28 网格、8 材质、0 纹理、19,456 三角形。完整单体含水帘尺寸约 3.205×16.510×14.626，最低 y=-12.5；此为瀑布下落部分，不是石槽悬空。支撑接地误差为约 -0.027 至 -0.014。每片石槽的内底高度为 3.12、2.42、1.72；沿局部 +Z 每级间距 3.465，落差 0.70。

真实槽底射线厚度约 0.288，水位高于内底约 0.237、低于采样槽沿约 0.21–0.23；叶尖采样高度比水位低约 0.07，可通过溢流口排水。三片石叶保持独立命名，石槽、支撑和静态水面分别合批，工厂克隆共享几何和材质。

没有新增贴图、依赖、灯光、着色器或第三方模型。沿用“生成设定图 → 本地可编辑几何 → GLB”流程。上一项已确认外部 3D 服务额度不足，本项没有再次提交生成、没有第三方产物下载。该本地 GLB 可保存、可重载，不需要生成服务或临时链接。

## 场景衔接

`src/boss-courtyard-blockout.ts` 将组合放在世界 (205.7,0,-38.8)，绕 Y 轴旋转 π/4，三级沿岛边斜向下降：

| 对象 | 世界 X / Z | 内底 Y |
|---|---|---:|
| 高槽 | 205.700 / -38.800 | 3.12 |
| 中槽 | 208.150 / -36.350 | 2.42 |
| 低槽 | 210.600 / -33.900 | 1.72 |
| 最终叶尖出水口 | 212.750 / -31.750 | 水位 1.965 |

岛面右边缘 X=212.5，最终叶尖已越过边缘，静态水帘向外下落。中槽架在现有低残墙上方；墙体和地形不改动。三个简单盒形代理随各级支撑同步移动、调整高度，保持三个物理体／碰撞体；中央叶纹地面、Boss／剑／树根、两风铃及用户选定的单座守卫不变。当前高／中／低槽和进水石口独立检测实体遮挡，靠近不会触发整组淡出；水面、瀑布和水滴排除，见 `../leaf-channel-visibility/README.md`。

## 验证

- `npm run build` 通过，保留既有大包体警告。
- `tests/leaf-water-channel.mjs` 通过：有限顶点／法线、共享、三片真凹槽、正反实体底面、低位溢水口、下沉水位、支撑接地、逐级高差、GLB 导出重载、实际出口在岛外、三个代理、6 段码头／外围通行、底座阻挡、遮挡注册和稳定重置，以及桌面／手机尺寸截图和非空像素。
- `tests/boss-courtyard-blockout.mjs` 生产回归通过：116 个中央地面采样、6 段往返、8 向闪避、碰撞、预警、前景淡出、既有单座石像和两风铃。已有正式模型累计 104,448 三角形，组合预算从 100,000 调整到 110,000；水槽单体仍受 35,000 上限约束。
- `tests/boss-arena.mjs` 生产回归通过：9 段通行、边界、Boss／钥匙、渡船往返、恢复和重置。上槽代理阻挡玩家于 X≈203.700，重置前后 192 bodies / 265 colliders。
- GLB 重载保持边界、三角形和材质数量。静态预览透明度为 0.43；当前水面没有流动、反射或实时折射承诺。
- 无捕获的 page / console / HTTP 错误。已查看最终单体斜视／俯视、游戏组合、岛边和手机近景，水路连续，中央场地保持可读。

固定水槽测试镜头显示本组为 183 calls / 230,874 triangles，隐藏为 151 / 211,190；透明水面双面绘制会使渲染增量 19,684 略高于模型几何 19,456。生产中央战斗镜头为 206 calls / 260,810 triangles、684 geometries / 30 textures；相对上一项同战斗镜头增加 16 calls / 13,812 可见三角形。这些是电脑自动化浏览器测量，不代表真机帧率。材质／几何数量已有积累，后续性能验证仍需覆盖入口和岛边视角。

本项沿用现有 Three.js 模型工厂、材质合批、Rapier 简单代理和浏览器截图／玩法回归；未增加像素比较基线，场景仍逐项制作。已使用 Graphics Builder 模型／技术美术及 QA 检查表。没有重复生成设定图或扩展其他道具。

第 8 项静态 GLB 不包含实时水流着色器；后续已在 `src/leaf-channel-water.ts` 和游戏运行时完成动态水流／瀑布，见上述第 9 项记录。未增加流水音效、部署、发布打包、全关卡通关或做手机真机性能测试。
