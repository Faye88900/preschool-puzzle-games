## 实现

`src/courtyard-vegetation.ts` 包含 `createCourtyardPlant(kind)` 六类模块和 `createCourtyardVegetation()` 完整布置工厂，均缓存并共享几何和材质。使用叶片折面、少量叶柄、拱形蕨茎、细草与米色穗头、三支垂藤和扁平苔藓块，以鼠尾草绿／橄榄绿为主、白花点缀。植物在实际关卡尺寸下布置，不以概念图当精确测绘。

布置共 117 处，按前／后／左／右四区合批，16 meshes／94,426 triangles／4 个共享 MeshStandardMaterial，无新贴图、依赖、灯光或透明卡片。采用顶点色与低面数轮廓，不逐帧更新或投射细叶阴影。四区分别保留剔除范围，避免每株独立绘制。模块工厂保留单体编辑入口，布局位置记录在组的 `userData.placements` 中。

`src/boss-island.ts` 将植被组放在庭院中心，世界 (187.5,0,-25)，不加入物理代理或建筑遮挡组。所有新增顶点的平面半径至少约 18.121，比叶纹圆盘半径 15 多约 3.12；西侧码头入口区域无植被。原石墙的少量绿化及既有道具位置保持，水槽内部和流路留空。

## 验证与性能

`npm run build`、`tests/courtyard-vegetation.mjs`、生产 `tests/boss-courtyard-blockout.mjs` 通过。测试环境沿用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_BROWSERS_PATH` 和 `TEST_URL`；植被测试使用开发服务，生产庭院测试使用预览服务。

六类模型的坐标／法线／颜色均为有限值，克隆共享资源，两份 GLB 重载后的三角形、材质配色及边界一致。植被与所有水流线段相交 0 次；六段实际键盘通行目标误差均小于 0.20。刚体／碰撞体在重置前后均为 192／265。生产测试另覆盖 116 点中央地面、码头往返、八向闪避、道具阻挡、Boss 攻击预警、前景淡出与手机画面，无 page／console／HTTP 错误。

中央镜头对照：隐藏本组为 230 calls／281,654 triangles，显示为 245／375,900，可见增量 15 calls／94,246 triangles；全组成本 16 calls／94,426 triangles。生产场景资源为 766 geometries／34 已上传纹理；专用测试切换近景后记录 769／36，后者含其他可见场景资源，本植被没有贴图。相比首轮 177,856 三角形，最终通过减少重复小叶、花瓣及穗头细分降至 94,426，保留 95,000 三角形及 16 meshes 上限断言。

已人工查看六类单体、整体前后对照、入口／树根／水槽近景及手机横竖屏战斗图，修正了初版叶面方向、叶柄连接和蕨叶与主茎的间隙。沿用固定视图截图、非空像素、几何及路径检查，不冻结严格像素基线。
