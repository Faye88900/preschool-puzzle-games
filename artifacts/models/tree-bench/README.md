## 结构与尺度

两段弧形无靠背木座面，前后缺口朝向 +Z / -Z，圆心位于原点、脚底 y=0。外观包括三条弧形木板、圆角石脚、内缩木支撑和弧形裙板、铜色连接件及青绿叶饰。

世界单位尺寸约 X=6.510、Y=0.837、Z=5.867，座面高度 0.800。中央实际留空；通行缺口经角色实际步进检查可通过。实际落地弧度略微调整，以给端部石脚及角色留下通行空间。

六个合并材质网格，共 16,112 三角形。两张 128×128 程序纹理提供木纹和石材变化。重复工厂调用共享几何、材质与纹理。

视觉模型与碰撞分开：一个固定刚体，24 个局部立方体跟随两段座椅和四个端脚；缺口和中央没有整圈封闭碰撞。

## 接入范围

替换古树广场的两张直长椅；水井旁及第二关的原长椅保留。树根花丛收进座椅内圈，相邻藤格架左移 0.4 单位避免相交。古树、铺地环、出口路线、任务及 UI 逻辑保留。
