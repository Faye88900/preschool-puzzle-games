# 暗甲小骑士

根据本轮确认的 `output/imagegen/round-dark-knight-v6.png` 制作。运行时工厂与动画在 `src/dark-knight.ts`；仅桥后第一只练习怪和后续普通盾怪使用新骑士。最终钥匙守卫保留旧叶怪、皇冠、1.9 倍大小与原动画，等待另行设计。练习怪仍一次命中即可通过，拿着放低的盾；后续骑士才举盾挡风。

## 文件

- `dark-knight.glb`：可单独查看的静态模型，含分开的身体、手脚、盾牌和披风节点；动画由运行时代码驱动，不含烘焙动画片段。
- `front.png`、`side.png`、`back.png`、`three-quarter.png`：实际 Three.js 模型视图。
- `warn.png`、`lunge.png`、`rest.png`、`stun.png`：实际状态姿态。
- `game-desktop.png`、`game-mobile.png`：桥后第一只小骑士，开发服务器内实际画面，遭遇位置由测试设置。
- `game-shield-encounter.png`：后续普通盾骑士。
- `metrics.json`：结构、握把连接、姿态、绘制与错误检查结果。
- `animation/preview.gif`：前版独立展示场景的动作预览，保留作对照；当前表情和退场以 `feedback.gif` 为准。
- `animation/report.json` 与同目录截图：巡逻路径、转身速度、动作过渡、挡风反应和受击表情检查。
- `animation/encounter.gif`：游戏场景中的追击与实际命中；遭遇位置由测试设置，随后推进正常物理/敌人逻辑。
- `animation/feedback.gif`：当前版本的休息、受击叉眼、2/2 → 1/2 扣血和灰化散尘；近景相机与遭遇位置由测试设置，阶段间略去等待时间。
- `health/`：重设计血条的全血/半血、桌面/平板/竖屏/横屏与近景截图，`report.json` 记录真实扣血残影的宽度采样及错误检查。旧 `animation/feedback.gif` 的血条是前版，当前样式以此目录为准。

## 构造与范围

圆形头盔、弯曲眉甲和开孔面罩、橙红眼光、短披风、两只甲靴、独立持盾。单只模型 39 个网格、25,792 三角形、12 个几何体、8 个共享材质，无贴图；包含通常隐藏的四个受击眼部叉形网格。静态 GLB 大小见 `metrics.json`。使用现有 Three.js 与项目圆角几何工具，无新依赖。

玩法沿用原来的预警、冲刺、休息破绽、风魔杖命中与掉钥匙流程，未改变伤害范围或地形碰撞。三语小骑士提示同步为盾牌；小向导仍描述最终守卫的大叶子。完整重开将小骑士的盾恢复为初始姿态。

普通骑士在出生点附近往返巡逻，端点停顿并平滑转身，四角地形检查防止穿过树篱。发现玩家后短暂停顿 0.35 秒、收紧眼神并追近，普通盾骑士同时举盾。追击速度 1.8 单位/秒，进入 2.5 单位且朝向正确才蓄力；玩家在起手期间拉到 3 单位以外则重新追击。蓄力前段跟随玩家，末段锁定方向，便于侧移躲开；冲刺后放盾，保留 2.6 秒反击空档。丢失视线只记住最后位置 1.8 秒，玩家逃出出生点 12 单位范围后脱战并返回，抵达后才重新发现玩家。半径感知的路径检查与每 0.4 秒至多一次的网格搜索处理树篱拐角；硬移动边界放宽至 14 单位，避免冲刺撞在旧出生点 2.4 单位限制上。最终 Boss 的模型与原行为保持原样。

脚步随实际移动速度变化，身体、手臂和披风平滑过渡。眼睛扩大并移到眉甲下方可见位置，支持巡逻眨眼、警觉睁眼、攻击斜眯眼、收招疲惫眼和受击惊讶/叉眼。受击叉眼持续至眩晕结束，挡风有盾牌回弹。普通怪归零后播放 1.25 秒哑光灰化、颗粒溶解和 48 粒灰尘散去，身体保持原尺寸。灰化只在首次击败时缓存单只角色材质副本，不改变其他活怪的共享材质；重开恢复原材质、眼神与完整身体，并隐藏灰尘。减弱动态关闭步态、摇摆、眨眼和灰尘漂移，保留功能姿态、表情与灰化退场。

头顶血条改为 86×17 CSS 像素的骑士徽记与切角金属细框，暗红填充、深色空槽，盾怪有两段生命刻度。去掉条内数字，当前/总生命保留在无障碍值中。红条快速扣减，暖色残影延迟回落；重开立即恢复满血，减弱动态禁用残影延迟和徽记亮度动画。盾牌挡住攻击时保持满血；仅在附近、有视线且关卡处于可操作状态时显示，死亡、暂停、对白和离屏时隐藏。使用 DOM 投影跟随角色，含三语无障碍标签，无新贴图或常驻 WebGL 绘制。

血条造型参考实际战斗截图：[《旷野之息》](https://whatjeffwatched.com/blog/reviewing-the-legend-of-zelda-breath-of-the-wild-is-the-switchs-original-open-world-adventure-as-good-as-everyone-says)的细红黑计量条，以及 [《TUNIC》](https://forest.watch.impress.co.jp/docs/serial/gprecommend/1417415.html)的深色描边与切角。徽记沿用本项目骑士盾面的菱形，扣血残影是本项目的反馈设计，没有复制或下载游戏素材。

参考 [任天堂《御天之剑》访谈](https://iwataasks.nintendo.com/interviews/wii/zelda-skyward-sword/2/2/)的姿态、距离与破绽设计，以及 [Guerrilla《地平线：西之绝境》访谈](https://blog.playstation.com/2021/12/06/horizon-forbidden-west-outsmart-your-enemies/)的攻击意图与丢失视线后搜索原则。上述数值是本项目入门怪的调整，并非这两款游戏的实测参数。
