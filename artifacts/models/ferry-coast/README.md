# 风之花园海边渡口

最新范围：空岛世界不变，仅码头及去守卫岛的航线是局部海湾。此前650×650的大海面已收回局部；按用户要求，局部水面由50×44加宽为90×70，守卫岛移远35，实际航线约58、航行9秒。周边云海与远处悬浮岛恢复原有高度，沙岸/礁石也限于码头范围。当前环境为16,760个三角面、9个网格；新范围测试及整岛实景见 `../ferry-coast-scope/README.md`。下面制作记录中旧范围、低云升高和远岛降到海平面的描述已被本段取代。

按 `artifacts/concepts/wind-sail-dock-2026-10-27/dock-design-v2-sea.png` 完成剩余环境，并按最新要求让登船正前方保持敞开。

| 项目 | 实现 |
| --- | --- |
| 海面、细波、岸边浪花 | `src/ferry-coast.ts` 的连续大海面、深浅水色、解析波纹/高光、随时间推进的岸边泡沫；本地标准材质 shader，无额外反射渲染通道 |
| 草地、沙地、礁石岸线 | `src/ferry-shore-layout.ts` 两端岸线；草地轮廓和道路随岸线裁切，渐变沙滩接入海中，52块实例化礁石避开上下船通道 |
| 桥下木桩与斜撑 | 保留真实几何结构，切掉桥下原来的整块岛面并下降海平面，露出水线附近的柱与斜撑 |
| 系船绳、绳圈 | 桥面边角增加系船桩与螺旋绳圈；侧绳仅在船停靠该端时显示，航行中两端均解开 |
| 叶形灯 | 木杆、弧形挂臂、发光奶油色灯芯与两片叶罩，使用发光材质，没有新增动态灯 |

| 敞开登船口 | 删除入口中间的绳索、挂钩、内侧挡路木桩及端部碰撞；保留栈桥两侧护栏，侧边系船绳不穿过中央通道 |

池塘水面、椭圆边框、荷叶、水纹和旧芦苇已经移除。原来的整块地板碰撞改为和草地、沙滩、守卫岛地表一致的静态三角网格，海峡中间没有隐形陆桥。岸边树篱及其碰撞同时裁到岸线内侧。海平面 Y=-.65，小船根节点 Y=-.8，船壳底部约-.786，因此船壳有吃水；人物在船上的局部站位仍为原来的1.3，往返流程仍为6秒。

环境外侧的低云升到天空，远处海岛降低到海平面附近，渡口视野呈现海面而不是云海。其它任务与地图拓扑保持原有路线。

`tests/ferry-coast.mjs`：检查59,210个三角面、9个网格的海岸环境几何、开放入口、被移除的池塘、实际草地/海床碰撞高度、水中船壳与支撑，及海面真实像素变化。26,000个像素采样中24,754个随波纹相位改变，同一相位重绘差异为0；暂停、减少动态状态、航行中的海面推进、停靠侧绳、手机按钮返程和重置均有断言。减少动态状态测试手动同步游戏现有的偏好字段，不声称新增了系统偏好实时监听。

`tests/rope-dock.mjs`：更新敞开入口后的码头 GLB 与模型图，15个网格、29,124个三角面，三块碰撞区域（板面、两侧栏杆），入口中心射线无阻挡。`tests/rope-dock-scene.mjs`：构建后核对走入码头、侧栏阻挡、入口无隐形阻挡、脚下地板、晶石前置条件、两端系船状态、暂停和触屏返程。`tests/boat-crossing.mjs` 保留宝箱问答拾取、守关者与钥匙、原出口、掉落恢复、重置和减少动态的广泛回归。
