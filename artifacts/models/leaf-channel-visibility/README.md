# 水槽靠近误透明修复

2026-10-29。用户截图中的误透明由整组水槽／长瀑布的合并外包框触发：玩家在框附近时，镜头射线穿过空白区域，也被当成实体遮挡。

## 修改

- `src/boss-island.ts` 把整组遮挡注册拆成高槽、中槽、低槽和进水石口四个独立组，瀑布和喷溅不作为遮挡物。
- `src/maze.ts` 在注册这四组时缓存非着色器的实体网格；外包框初筛命中后，再用镜头至玩家的实际线段检查实体表面。水面、瀑布和水滴不会触发淡出。
- 仅实际挡住玩家的槽组降至 0.16，其他槽保持 1；离开遮挡时恢复。保留现有插值与材质隔离，不改其他建筑的判断方式，也不更改水槽、模型、碰撞或镜头布局。
- `tests/leaf-water-channel.mjs` 的注册计数随四组拆分更新；新独立回归直接验证四组目标和实际行为。
