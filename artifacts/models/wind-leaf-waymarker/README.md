# 风叶路标 Three.js 模型

- 源码：`src/wind-leaf-waymarker.ts`，入口 `createWindLeafWaymarker()`。
- 原创概念：`output/art-direction/level3-old-oak-plaza/wind-leaf-waymarker-design-v1.png`。
- 地面中心为枢轴，Y 向上、+Z 为正面；宽 3.311 × 高 4.209 × 深 0.860 场景单位。
- 16 个按材质合并的网格，16,476 三角形，8 种材质；木、石、铜、青绿材质与现有环树座椅共享，无新增纹理或依赖。
- 叶轮组 `waymarker-rotor` 的本地枢轴为 (0,3.19,0.1)，三片叶子以 120 度分布；轮毂面对 +Z，可绕局部 Z 轴旋转，本次交付保持静态。
- 叶饰箭头组 `waymarker-leaf-arrow` 指 -X；风纹箭头组 `waymarker-wind-arrow` 指 +X，背面也有图标。
- `windLeafWaymarkerColliders` 提供石脚、柱身及两块箭头的四个盒碰撞。GLB 仅包含可视模型，不携带 Rapier 刚体；其他项目导入时需另接碰撞。
- 已接入古树广场通往风车桥前的北侧路肩 (6.5,0,37.8)，上箭头指向古树，下箭头指向风车桥方向。路标避开原有南侧路灯与前景树篱；“古树广场”旧文字牌已删除，其余中文提示牌保留；遮挡角色时淡化。
- `wind-leaf-waymarker.glb` 为 813,452 字节，已导出回读，面数和尺寸一致。
- `three-quarter.png`、`front.png`、`side.png`、`top.png` 为实际 Three.js 渲染；`metrics.json` 保存模型检查记录。

## 制作范围与预算

根据现有概念用 Three.js 本地生成原创几何：圆角石脚、木杆、铜箍、带内嵌浅色面的木箭头、三叶金色叶轮和叶脉、凸起图标及少量蕨叶。原始游戏模型不改动。材质按既有花园角色使用粗糙暖木、奶油石、青绿点缀与少量黄铜；沿用既有关卡日光、阴影、DPR 和遮挡系统，不新增灯光、着色器、机关或动画。

单体预算为最多 16 个网格、30,000 三角形和 0 新纹理；实际为 16 / 16,476 / 0。静态部件分别合批，保留两个箭头和独立叶轮，原生视锥裁剪。缓存实例共享资源，不增加资源管理抽象。

## 摆放修订

用户要求参考其他游戏调整位置并删除“古树广场”旧牌。观察参考：[Animal Crossing 玩家布景截图](https://www.breakflip.com/guides/99072.html) 的草地路肩路标，以及 [Kirby Waddle Dee Town 官方设施图](https://www.nintendo.com/jp/switch/arzga/town/index.html) 的设施侧边信息牌。本次采用的摆放判断：在选择方向之前看见路标，放到路肩，留出主行走面和牌面周围的空隙。此处为根据截图作出的设计转化，不代表参考游戏规定统一尺寸。

路标从 (10,0,43) 移到 (6.5,0,37.8)，箭头仍分别指向古树与风车。视觉、刚体碰撞和遮挡包围盒一起移动；测试额外确认旧牌已移除、新位置、两块箭头实际指向及桥方向通行。模型自身与独立 GLB 无需改变。
