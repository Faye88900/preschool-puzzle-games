## 实现

`src/floating-islands.ts` 的 `createFloatingRock(kind)` 与 `createDistantIsland(kind)` 缓存并共享几何、材质及一张 128×128 石纹。近景岩体具有闭合冠面和底面、错位层岩断面、厚侧岩块、少量裂隙及复用的庭院绿丛／垂藤。远景采用更少的轮廓面和侧岩块，绿色冠面沿岩顶铺设，单树由少量枝干和扁平树冠组成，长脊保留两处不等岩底。

| 模型 | 三角形 | 网格 |
|---|---:|---:|
| 碎岩 A | 2,442 | 3 |
| 碎岩 B | 2,330 | 3 |
| 碎岩 C | 2,122 | 3 |
| 近景套件 | 6,894 | 9 |
| 草顶小岛 | 445 | 2 |
| 单树浮岛 | 989 | 3 |
| 长条岩脊 | 669 | 2 |
| 远景套件 | 2,103 | 7 |

近景共两种材质，远景三种，石材与石纹跨套件共享。所有叶片和岩体为实体／不透明模型，没有新增透明卡片、新灯光、依赖、物理代理或逐帧更新。

`src/boss-courtyard-blockout.ts` 用 C／B／A 替换三个方块，挂点为世界 (202.5,6,-47)、(205.5,9.1,-47)、(208.5,12.2,-47)，三块分别有轻微倾斜且保持独立组。最低边界分别约 y=3.958、5.871、7.524，均在庭院后侧。群组保留既有 `boss-blockout-floating-rocks` 名称，后续漂浮动画可使用这些挂点。

`src/maze-island.ts` 使用六处远景，保留原缩放与高度。用户反馈渡船转向时岩石挡住视野后，将北侧长脊 z=-48 调至 -110、南侧小岛 z=32 调至 95；当前六处位置为 (-82,8,-28)、(-75,-3,45)、(128,10,-110)、(140,2,95)、(-28,5,-82)、(87,-6,91)。每种模块使用两次，总成本仍为 14 meshes／4,206 triangles。原主岛壳、地面、120 个云团、海湾范围及碰撞保持。渡船修正的最新截图与视线扫描见 `artifacts/models/boat-scenery-visibility/`；本目录先前场景截图和 metrics 保留为交付记录。

## 验证与成本

以下通过：

- `npm run build`，保留既有大包体警告。
- `tests/floating-islands.mjs`：有限几何／法线、克隆共享、三种不同轮廓、三块主岩体闭合边且有向体积为正、两份 GLB 重载、六处远景原高度、海面避让、九条巨剑视线射线、重置及桌面／手机画面。两份 GLB 的三角形、颜色／材质、贴图和边界均一致。
- 生产 `tests/boss-courtyard-blockout.mjs`：三块正式模型接入、116 点中央地面、六段通行、八向闪避、道具碰撞、Boss 攻击预警、前景淡出和手机画面。
- `tests/maze-ground.mjs`：原主岛壳、120 个云团、地面贴图、连续 UV、向上草地法线、重置资源复用及各区域桌面／手机画面。原主岛＋云＋远景整组在该展示镜头增加 11 次绘制，受新的 16 次上限约束。

没有 page／console／HTTP 错误。已查看近景套件、正／侧／底部、远景套件和场景及手机横竖屏图。首版过尖的重复侧岩改成厚断石，并缩短海湾远景的岩底以保持海面避让。

庭院道具组原 149,516 三角形，移除 36 三角方块并加入 6,894 后为 156,374，上限断言由 150,000 调为 160,000；植被独立保留 95,000 上限。生产中央视角为 249 calls／381,426 triangles／78 points，较前一步 245／375,900 增加 4 calls／5,526 triangles。远景由原两个大范围 InstancedMesh 改为可按岛剔除的具名组，此视角的远景可见性不同，不能用中央增量代表完整六岛成本。

专用测试在同一中央视角隐藏近景与远景为 240 calls／374,532 triangles，显示为 249／381,426，可见增量 9 calls／6,894 triangles，等于三块近岩，六处远景在该视角被剔除。生产场景记录 780 geometries／35 已上传纹理；单体套件均有一张石纹，跨套件共享。专用测试切换镜头后的资源数与生产中央记录不同，见 metrics。

测试沿用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_BROWSERS_PATH` 和 `TEST_URL` 环境变量；单体／原地形测试连接开发服务，生产庭院测试连接预览服务。沿用固定截图、非空像素、几何／视线断言和 GLB 重载，不建立严格像素基线。

## 限制

本步骤完成静态正式模型，不新增跳跃路径或可玩岛屿；漂浮动画和环境光效留待第 16 项。`tests/ferry-coast.mjs` 只更新了读取远景高度的接口，未重跑完整海湾／渡船流程，相关远景原坐标、高度和海面避让由专用测试覆盖。未部署、全关卡通关或进行手机真机性能测试。全场既有绘制／几何资源超过通用手机起始预算，手机尺寸截图不代表真机帧率。
