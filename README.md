# Preschool Puzzle Games · 幼儿益智小游戏

用 Three.js + Rapier 制作的 3D 小游戏，包含竞速和解谜两个关卡，支持电脑与手机。

[在线试玩](https://faye88900.github.io/preschool-puzzle-games/)

推送到 `main` 后，GitHub Actions 会自动构建并更新 GitHub Pages。部署状态可在仓库的 Actions 页面查看。

## 第一关 · 天空赛道

和 11 名电脑选手一起跑跳、躲障碍，前 8 名晋级，限时 90 秒。晋级后可乘云前往第二关。

## 第二关 · 解谜花园

自由探索花园，完成三个谜题，收集三把钥匙打开出口。没有倒计时，可以按任意顺序完成。

- **积木工坊**：把正方体放到方形机关上，打开铁门拿钥匙。
- **流水池塘**：转动水管，让水流到小花；花开后跳上去拿钥匙。
- **动物朋友**：用谷粒引导小鸡进入鸡舍，让它帮忙带回钥匙。

首页点击「选择关卡」即可进入第二关；按 **E** 互动、**H** 获取提示，手机使用互动和提示按钮。

## 运行

需要 Node.js 22.12 或以上。

```sh
npm install
npm run dev
```

打开 [本地首页](http://127.0.0.1:5188/)，点击「开始游戏」或「选择关卡」。电脑建议使用 Chrome / Edge。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 空格 | 跳跃 |
| Shift | 第一关冲扑 |
| E / H | 第二关互动 / 提示 |
| Esc | 暂停 / 继续 |

手机使用屏幕摇杆和按钮。首页设置可开关背景音乐、音效与语音。

构建：`npm run build` · 预览：`npm run preview` · 测试：`npm test`（需安装 Chrome）。

## 工坊向导 · 角色预览

打开 [NPC 三维预览](http://127.0.0.1:5188/?character=npc)，可拖动旋转、切换正侧背视图，查看待机、指向线索、点头鼓励动作，也可下载静态 GLB。动作由 Three.js 驱动，GLB 不含烘焙动画。

在 [第二关](http://127.0.0.1:5188/?level=2) 靠近积木工坊入口的安全帽向导，按 E 或点击「对话」进入六步分镜：双人对话 → 指向铁门 → 钥匙特写 → 机关特写 → 积木全景 → 回到玩家。点击「继续」或聚焦按钮后按 Enter / 空格推进；「退出对话」或 Esc 随时退出。对话期间冻结游戏操作，退出后平滑恢复；支持竖屏、减少动态效果，以及开门/取得钥匙后的对应台词。字幕朗读沿用游戏音效设置和浏览器中文语音。

角色在 `src/workshop-guide.ts` 中由几何体生成，沿用玩家坐标约定（朝向 -Z，站地时根节点 Y 为 0.68）。使用 `createWorkshopGuide()` 创建、`animateWorkshopGuide()` 更新动作、`setGuideExpression()` 切换表情。动画的 `elapsed` 参数为当前动作开始后的秒数；指向动作先转身观察，再伸手停留、收回，可用预览中的「重播动作」重看。减少动态效果时显示静态指向姿势。

工坊向导平时在积木区前方慢走，朝向行走方向；遇到玩家或积木停步。对话和暂停期间停止走动，结束后继续巡游，互动距离随 NPC 实际位置计算。
