# 云端冒险 · Bean Rush

Three.js + Rapier 3D 小游戏，支持电脑键盘和手机屏幕按钮。

- 第一关「天空赛道」：跑跳、避开障碍，前 8 名晋级。
- 第二关「解谜花园」：积木压机关、接通水管、引导小鸡，收集三把钥匙。
- 第三关「风语迷宫」：帮助园丁找工具，获得风力魔杖，放下风车桥，遇到暗甲小骑士，再观察叶盾钥匙守卫的攻击空隙，取得钥匙并从捷径返回出口。入口为 `?level=3`。
- WASD / 方向键移动，空格跳跃，Shift 冲扑，E 互动，H 提示，Esc 暂停。

## 交给同事上传

运行 `npm run build` 后，将 `dist` 内的全部文件和文件夹一起上传到网站的同一目录，保持名称和结构。素材来源和许可证也需一起保留。每次修改源码或素材后，交付前须重新构建。

网站入口为该目录下的 `index.html`。支持网站子目录；无需安装 Node.js 或重新构建。请通过 HTTP / HTTPS 网站打开。

## 维护源码

需要 Node.js 22.12 或以上：

```sh
npm ci
npm run dev
```

构建：`npm run build`，结果在 `dist`。本地预览：`npm run preview`。

首页设置内可切换中文、英文、马来文，也支持 `?lang=zh`、`?lang=en`、`?lang=ms`。本次仅切换文字，语音仍沿用原有中文朗读。
第三关的 E / 屏幕互动按钮会根据附近对象交谈、拾取或吹风；H 提示，Esc 暂停。第三关语音使用浏览器对应语言的朗读声音，设备需有相应语音。耗尽活力会回到安全点并保留本局进度；重新开始会清空本局，刷新不保存进度。
园丁任务：沿湿脚印寻找小车，推开后取出铲子，带回并在小花坛种下花苗；开花后获得风魔杖。可先自由探索再找园丁。
第三关复用 `public/models/SOURCES.md` 已登记的免费模型和原有音效；风车、魔杖、暗甲小骑士等为本项目组合建模。
首页设置可开关背景音乐、音效与语音，以及「4岁辅助转向」。辅助默认关闭，也可在赛道暂停菜单中切换：靠近左右边缘时帮助回正，跳跃和躲避仍由玩家控制。
第三关探索音乐为《Whispering Maze》，交战时切换为《Gust of the Crystal Wand》，脱战或击败敌人后接续探索音乐；对话和花儿合唱时降低背景音乐音量。
推送到 `main` 后，现有 GitHub Actions 会构建并更新 GitHub Pages。

## 源码交付范围

同事需要继续开发时，交付 `src/`、`public/`、`.github/`、`.gitignore`、`index.html`、`package.json`、`package-lock.json`、`tsconfig.json`、`vite.config.ts` 和本说明。换电脑后运行 `npm ci`，再运行 `npm run dev`。

交付已清理概念图、生成提示词、旧源码及模型导出备份、截图、录像、临时测试脚本和日志。`public` 与 `src/vendor` 内的素材来源、许可证及类型声明属于交付内容。`public/models/SOURCES.md` 保留历史来源记录，里面提到的开发资料不随交付提供。

压缩源码时不要包含 `.git/`、`node_modules/`、日志或环境密钥；`dist/` 仅在需要同时提供可上传的网站时附带。
