# Preschool Puzzle Games

适合幼儿的 3D 浏览器小游戏，支持电脑键盘和手机触控。

- **天空赛道**：跑跳躲障碍，前 8 名晋级。
- **解谜花园**：搬积木、接水管、帮助小鸡，收集三把钥匙打开大门。

## 开始运行

安装 Node.js 22.12 或以上，然后执行：

```sh
npm install
npm run dev
```

打开 [游戏首页](http://127.0.0.1:5188/)，点击「开始游戏」或「选择关卡」。

## 操作

| 操作 | 电脑 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 跳跃 | 空格 |
| 第一关冲扑 | Shift |
| 第二关互动 / 提示 | E / H |
| 暂停 | Esc |

手机使用屏幕摇杆和按钮；首页设置可开关音乐、音效与语音。

开发命令：`npm run build` 构建，`npm run preview` 预览，`npm test` 测试（需安装 Chrome）。
